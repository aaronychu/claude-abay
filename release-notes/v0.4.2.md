# Claude Code A+BAY v0.4.2

这版修复 `v0.4.1` 中 Electron 桌面端 Skills 导入入口缺少主进程实现的问题。

## Fixes

- 修复在「设置 → 技能」中添加技能时报错：
  `Electron command install_skills_from_paths is not implemented in the Electron host yet`。
- Electron 桌面端现在支持选择单个或多个 skill 文件夹，并安装到 `~/.claude/skills` 或当前 `CLAUDE_CONFIG_DIR/skills`。
- Electron 桌面端现在支持选择单个或多个 zip 包，自动解压后安装其中包含 `SKILL.md` 的 skill。

## 安装

到本页面底部的 Assets 里，按系统和 CPU 架构下载对应文件：

| 平台 | 文件 |
|------|------|
| macOS Apple Silicon（M 系列） | `Claude-Code-ABAY-0.4.2-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-ABAY-0.4.2-mac-x64.dmg` |
| Windows x64 | `Claude-Code-ABAY-0.4.2-win-x64.exe` |
| Linux x64 | `Claude-Code-ABAY-0.4.2-linux-x86_64.AppImage` 或 `Claude-Code-ABAY-0.4.2-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-ABAY-0.4.2-linux-arm64.AppImage` 或 `Claude-Code-ABAY-0.4.2-linux-arm64.deb` |
