# Claude Code A+BAY v0.4.12

这是 `v0.4.11` 之后的桌面端修复版本，重点处理 Windows 10 上侧边栏全透明、没有磨砂质感的问题，同时不改变 Windows 11 的原生 acrylic 表现。

## Highlights

- **Windows 10 sidebar 兼容**：Electron preload 会读取真实 Windows build，仅在 Windows 10（build < 22000）启用 CSS 磨砂 fallback，避免侧边栏变成全透明。
- **Windows 11 保持原生效果**：Windows 11 不再命中兼容 fallback，继续使用 Electron / DWM 的原生 acrylic 路径。
- **发布流程更稳**：保留 unsigned draft release 路径，缺少 macOS/Windows 签名证书时仍可生成测试安装包；Windows 未签名 installer smoke 不再阻断后续结构校验和 artifact 上传。

## Changes

- `desktopHost.platform` 增加 host 平台信息，用于 renderer 精确区分 Windows 10 和 Windows 11。
- AppShell 只在 Windows 10 桌面端追加 `app-shell--windows10` class。
- sidebar 的 CSS blur/tint fallback 只作用于 `.app-shell--windows10`，避免影响 Windows 11。
- release workflow 会在缺少签名 secrets 时保留 draft release，适合先下载测试包。

## Notes

- GitHub Release 正文以 `release-notes/v0.4.12.md` 作为唯一来源。
- 桌面端发布版本号来源是 `desktop/package.json`；发布时必须确保版本号、Git tag `v0.4.12` 和本文件严格一致。
- macOS 未配置签名/公证 secrets 时，release 会保持 draft；Windows 未签名构建可能显示 SmartScreen 提示。

## 安装

在本页面底部 Assets 中按系统和 CPU 架构下载：

| 平台 | 文件 |
|------|------|
| macOS Apple Silicon（M 系列） | `Claude-Code-ABAY-0.4.12-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-ABAY-0.4.12-mac-x64.dmg` |
| Windows x64 | `Claude-Code-ABAY-0.4.12-win-x64.exe` |
| Windows ARM64 | `Claude-Code-ABAY-0.4.12-win-arm64.exe` |
| Linux x64 | `Claude-Code-ABAY-0.4.12-linux-x86_64.AppImage` 或 `Claude-Code-ABAY-0.4.12-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-ABAY-0.4.12-linux-arm64.AppImage` 或 `Claude-Code-ABAY-0.4.12-linux-arm64.deb` |

### macOS

双击 DMG，把应用拖入“应用程序”。未签名测试构建请使用 release assets 中附带的 `install-macos-unsigned.sh`。

### Windows

双击 `.exe` 安装。未签名构建出现 SmartScreen 时可选择“更多信息”→“仍要运行”。

### Linux

AppImage：

```bash
chmod +x Claude-Code-ABAY-0.4.12-linux-x86_64.AppImage
./Claude-Code-ABAY-0.4.12-linux-x86_64.AppImage
```

deb：

```bash
sudo apt install ./Claude-Code-ABAY-0.4.12-linux-amd64.deb
```
