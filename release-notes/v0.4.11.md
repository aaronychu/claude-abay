# Claude Code A+BAY v0.4.11

这是 `v0.4.10` 之后的 A+BAY 桌面体验修订版本，重点保留 fork 定制、修复桌面 shell 视觉细节，并为后续同步上游补齐操作文档。

## Highlights

- **顶部栏改为当前标题**：桌面端顶部不再显示多个 tab，改为展示当前会话或页面标题；标题区域可继续拖拽窗口，右侧工具按钮保持可点击。
- **恢复真实磨砂 sidebar**：macOS 使用原生 `vibrancy`，Windows 使用 `acrylic`；应用主题切换会同步 Electron native theme，避免系统主题和应用主题不一致时侧边栏发灰或过透。
- **整理 A+BAY UI 线条和背景**：继续收敛设置页、聊天输入区、工作区和侧边栏周围多余的硬分隔线，保持 light / dark / white 配色一致。
- **补齐 Skills 本地导入桥接**：恢复 Electron host 的 `install_skills_from_paths` command，避免设置页导入文件夹或 zip skill 时提示 command 未实现。
- **新增 fork 同步文档**：新增 `docs/reference/abay-fork-sync-guide.md`，记录 A+BAY 相对上游需要长期保留的 branding、UI、发布、OAuth、Skills 和同步检查步骤。

## Changes

- 侧边栏保留 `app-title.png` / `app-icon.png` 视觉入口，并保持标题区域 drag region 不影响按钮和右键菜单。
- `TabBar` 收敛为单标题栏，移除多 tab 渲染、滚动、关闭、拖拽排序和右键关闭菜单。
- Electron 增加 `desktop:app:set-theme` IPC，只允许 `white`、`light`、`dark` 三种主题值。
- `uiStore.applyTheme()` 会将 renderer 主题同步到 Electron 主进程，`white` / `light` 映射为 native light，`dark` 映射为 native dark。
- `conversationService` 继续使用 `abayOAuthService`，避免同步上游后回退到旧 OAuth service。

## Notes

- GitHub Release 正文以 `release-notes/v0.4.11.md` 作为唯一来源。
- 桌面端发布版本号来源是 `desktop/package.json`；发布时必须确保版本号、Git tag `v0.4.11` 和本文件严格一致。
- macOS 正式公开发布依赖签名和公证 secrets；Windows 未配置签名时仍可安装和自动更新，但可能显示 SmartScreen 提示。

## 安装

在本页面底部 Assets 中按系统和 CPU 架构下载：

| 平台 | 文件 |
|------|------|
| macOS Apple Silicon（M 系列） | `Claude-Code-ABAY-0.4.11-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-ABAY-0.4.11-mac-x64.dmg` |
| Windows x64 | `Claude-Code-ABAY-0.4.11-win-x64.exe` |
| Windows ARM64 | `Claude-Code-ABAY-0.4.11-win-arm64.exe` |
| Linux x64 | `Claude-Code-ABAY-0.4.11-linux-x86_64.AppImage` 或 `Claude-Code-ABAY-0.4.11-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-ABAY-0.4.11-linux-arm64.AppImage` 或 `Claude-Code-ABAY-0.4.11-linux-arm64.deb` |

### macOS

双击 DMG，把应用拖入“应用程序”。正式签名和公证产物应直接通过正常 Gatekeeper 流程。

### Windows

双击 `.exe` 安装。未签名构建出现 SmartScreen 时可选择“更多信息”→“仍要运行”。

### Linux

AppImage：

```bash
chmod +x Claude-Code-ABAY-0.4.11-linux-x86_64.AppImage
./Claude-Code-ABAY-0.4.11-linux-x86_64.AppImage
```

deb：

```bash
sudo apt install ./Claude-Code-ABAY-0.4.11-linux-amd64.deb
```
