# Claude Code A+BAY v0.4.1

这版主要补齐桌面端 UI 打磨和 Skills 导入能力，方便直接在设置里维护本地技能。

## Highlights

- **Skills 支持图形化导入**：在「设置 → 技能」中可以选择单个或多个技能文件夹，也可以选择单个或多个 zip 包；zip 会自动解压并安装到 `~/.claude/skills` 或当前 `CLAUDE_CONFIG_DIR/skills`。
- **技能导入更适合批量管理**：支持直接导入包含 `SKILL.md` 的单个 skill 文件夹，也支持导入包含多个 skill 子目录的父文件夹或 zip。同名技能会覆盖更新。
- **桌面 UI 继续贴近 Codex 风格**：恢复并强化 light / dark 配色、sidebar 玻璃效果、设置页背景、标题栏拖拽区域和品牌资源显示。

## Fixes

- 修复 sidebar 顶部标题区域无法拖拽窗口的问题。
- 移除 sidebar 顶部 GitHub 图标。
- 移除右侧 Review 面板及其入口。
- 修复暗色主题下部分设置按钮文字和 composer 区域颜色不协调的问题。
- 修复 sidebar 浮层菜单被拖拽层或背景层挡住，导致右键删除等操作无法触发的问题。
- 修复 app logo 和 app title 在不同页面的比例与展示问题。
- 移除旧作者相关展示信息和站点配置。

## Notes

- macOS / Windows 仍可能因为未签名而出现系统安全提示，首次安装按 `v0.4.0` 的方式手动放行即可。
- 本版本会由 GitHub Actions 自动构建桌面端安装包，完成后可在 Releases 页面下载。

## 安装

到本页面底部的 Assets 里，按系统和 CPU 架构下载对应文件：

| 平台 | 文件 |
|------|------|
| macOS Apple Silicon（M 系列） | `Claude-Code-ABAY-0.4.1-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-ABAY-0.4.1-mac-x64.dmg` |
| Windows x64 | `Claude-Code-ABAY-0.4.1-win-x64.exe` |
| Linux x64 | `Claude-Code-ABAY-0.4.1-linux-x86_64.AppImage` 或 `Claude-Code-ABAY-0.4.1-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-ABAY-0.4.1-linux-arm64.AppImage` 或 `Claude-Code-ABAY-0.4.1-linux-arm64.deb` |
